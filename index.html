Создайте комнату, отправьте другу 5-значный код — и играйте напрямую, браузер ↔ браузер.
Сигнальный обмен идёт через публичные BitTorrent-трекеры (Trystero), игровые данные — напрямую по WebRTC.
Код комнаты:
Выберите режим игры

Противник (ИИ) (Живых: 10)

Технологии: WebRTC DataChannel (прямое соединение браузеров) + библиотека Trystero — обнаружение пиров через публичные BitTorrent (WebTorrent) трекеры по WebSocket. Никакого игрового сервера: каждый клиент хранит только свой флот и честно сообщает его координаты лишь в ответ на выстрелы соперника.
